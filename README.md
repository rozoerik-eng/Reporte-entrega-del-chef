# 🍽️ Dashboard Ejecutivo — Entrega del Chef

Dashboard interactivo de Meta Ads para seguimiento mensual de campañas publicitarias.

## 🔗 Ver Dashboard en vivo

**[→ Abrir Dashboard](https://rozoerik-eng.github.io/Reporte-entrega-del-chef/)**

## 📊 Contenido

| Sección | Descripción |
|---|---|
| Resumen Ejecutivo | KPIs clave: inversión, alcance, CTR, CPL, ROAS |
| Rendimiento por Campaña | Tabla comparativa con mejor/peor anuncio |
| Rendimiento por Creativo | Ranking de anuncios por eficiencia |
| Embudo de Ventas | Impresiones → Clics → Leads → Ventas |
| Crecimiento Mensual | Gráficos de evolución histórica |
| KPIs Anuales | Totales acumulados del año |
| Insights Automáticos | Análisis generado de los datos |
| Recomendaciones | Plan de acción para el mes siguiente |
| Actualizar Datos | Agregar nuevo mes sin borrar histórico |

## 🔄 Cómo actualizar mensualmente

1. Abrir el dashboard → pestaña **"Actualizar"**
2. Ingresar los datos del nuevo mes (Meta Ads + CRM)
3. Clic en **"Agregar Mes al Dashboard"**
4. Los gráficos se actualizan automáticamente
